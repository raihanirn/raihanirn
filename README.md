### 🚀 Proyek Unggulan

#### ♻️ Sistem Informasi Bank Sampah Teratai
> Aplikasi berbasis web untuk pencatatan dan pemantauan transaksi pengelolaan sampah di lingkungan RW 04 Pondok Puncung Indah 1, Tangerang Selatan.
- **Fitur Utama:** Pencatatan transaksi nasabah, manajemen data sampah, dan pemantauan saldo secara *real-time*.
- **Teknologi:** HTML, CSS, JavaScript, Firebase (Hosting, Firestore Database, Authentication).
- **Live Demo:** [bank-sampah-teratai.web.app](https://bank-sampah-teratai.web.app)
